# KeyRing

KeyRing 是一款本地优先的密码管理应用，主打免费、安全、易用和开源。

它适合用来管理日常生活里的各种账号密码：邮箱、社交平台、购物平台、开发者账号、银行卡相关服务等。你可以把账号、用户名、密码、网址和备注保存在自己的设备里，并在同一局域网内的设备之间同步。

KeyRing 不要求注册账号，不依赖云端服务。你的数据默认只保存在自己的设备中。

## 为什么做 KeyRing

我们每天都会面对越来越多的账号密码。常见做法看起来方便，但风险很高：

- 多个平台共用同一个密码
- 使用生日、手机号、姓名缩写等容易猜到的信息
- 为了记住密码，把密码写在备忘录、聊天记录或表格里
- 密码太复杂记不住，只能频繁找回密码
- 不放心把全部密码交给第三方云服务

KeyRing 想解决的是一个很朴素的问题：让密码足够复杂，同时又能被安全、方便地管理。

## KeyRing 怎么解决

KeyRing 的设计重点是本地、安全、简单：

- 本地存储：账号密码保存在设备本地数据库
- 无需登录：不需要注册账号，也不需要云端账户
- 安全解锁：应用使用系统认证，工作区可选择系统验证或独立自定义密码
- 局域网同步：设备在同一 Wi-Fi 下可通过验证码配对同步
- 随机密码：新增账号时可以快速生成复杂密码
- 备注管理：支持记录安全问题、恢复邮箱、备用说明等长文本

## 主要功能

- 保存、查看、编辑和删除密码条目
- 标记常用密码
- 快速生成高强度随机密码
- 查看密码强度
- 复制账号、用户名、密码等信息
- 多行备注
- 应用在后台满两分钟后自动锁定，详情、编辑和设置页同样生效
- 首页展示密码2、密码3等自定义保密项，各项独立显示、隐藏和复制
- 局域网设备发现和双向同步
- 同步中可停止，失败或停止后可重新同步
- 兼容旧版本本地数据

## 首次使用

1. 打开 KeyRing。
2. 通过系统身份验证解锁应用。
3. 在“管理工作区 → 访问验证”选择系统验证（指纹、面容或设备密码）或自定义密码，也可保留无需额外验证。
4. 进入首页后，点击新增按钮创建第一条密码记录。

请妥善记住工作区自定义密码。验证设置仅在本机生效，不随同步或导出传输；更改或关闭保护需要通过当前验证。

## 添加密码

新增密码时可以填写：

- 账号名：例如 GitHub、微信、邮箱
- 用户名：登录时使用的用户名或邮箱
- 密码：可以手动输入，也可以自动生成
- 网址：可选
- 备注：可选，适合记录安全问题答案、恢复邮箱、备用说明等
- 附加密码：点击“添加密码”生成密码2、密码3等，可改为交易密码等自定义名称
- 常用：打开后更方便在列表中找到

保存后，记录会写入本地数据库。

## 生成密码

在新增或编辑页面点击生成按钮，KeyRing 会生成包含大小写字母、数字和符号的随机密码。

如果生成结果不满意，可以重复点击生成按钮。每次生成都会重新随机，避免连续生成结果相同。

## 查看和编辑

在首页点击密码条目可以进入详情页。详情页可以查看完整信息，也可以进入编辑页面修改用户名、密码、网址、备注和常用状态。

删除密码前请确认该记录不再需要。删除后不会自动从云端恢复。

## 从 Chrome 导入

在 Chrome 密码管理器导出 CSV 后，打开 KeyRing 的“导入 → Chrome 密码 CSV”。先检查新增、重复和冲突记录，再确认写入当前工作区；冲突默认保留本地记录，可选择更新。

这是手动导入，Chrome 数据更新后可再次导入，不会持续读取浏览器密码库。CSV 包含明文密码，用完后请妥善删除。

## 局域网同步

KeyRing 支持同一局域网内的设备同步数据，不需要登录云服务。

使用步骤：

1. 两台设备连接到同一个 Wi-Fi 或局域网。
2. 两台设备都打开 KeyRing。
3. 在其中一台设备上启动同步。
4. 等待发现另一台设备。
5. 根据界面提示输入或确认验证码。
6. 验证通过后开始同步。

验证码有有效期。取消或超时后，需要两端重新开启同步。

## 同步规则

同步会比较两端的密码条目：

- 本地没有的记录会新增
- 两边都有的记录会比较更新时间
- 更新时间较新的版本会覆盖较旧版本
- 对方版本较旧时，应用会提示兼容性警告

建议所有设备尽量升级到同一版本后再同步，减少冲突判断不一致的风险。

## 历史数据兼容

升级到带兼容机制的版本后，KeyRing 会检查本地数据库状态：

- 新安装且没有历史数据时，会直接初始化为当前数据版本
- 已经有历史数据但缺少版本信息时，会标记为需要兼容处理
- 应用会准备数据库备份，降低升级过程中的数据风险

升级后建议先在单台设备打开应用确认数据正常，再进行多设备同步。

## 数据导出

升级前建议在首页点击导出按钮，生成一份 JSON 备份文件。文件会优先保存到系统下载目录的 KeyRing 文件夹中，导出成功后，文件路径会自动复制到剪贴板。

导出的 JSON 会包含完整账号、用户名、密码、网址和备注，请只保存到可信位置，并避免上传到不受信任的云盘或聊天工具。

v0.1.1 兼容过渡版本重点用于覆盖旧版安装后导出数据。后续切换正式签名版本前，请先完成数据导出。

## 数据安全说明

KeyRing 的设计偏向本地使用：

- 密码条目存储在本地 SQLite 数据库中
- 工作区自定义密码的加盐派生验证值、验证方式和设备标识使用系统安全存储保存
- 工作区验证属于应用内访问控制，SQLite 条目库本身不是独立加密保险库
- 受保护工作区不进入手机系统自动填充候选
- iOS 和 macOS 使用 Keychain
- Android 使用系统加密存储能力
- 局域网同步需要验证码确认

当前同步是局域网内设备间传输，不是云端备份。重要数据建议定期使用系统级备份方式保护。

## 常见问题

### 为什么发现不了另一台设备？

请确认两台设备在同一个局域网内，并且系统没有阻止局域网访问、Bonjour/mDNS 或防火墙连接。部分公共 Wi-Fi 会隔离设备，导致无法互相发现。

### 同步提示对方版本较旧怎么办？

建议先把两台设备都升级到最新版本，再重新同步。如果必须和旧版本同步，请确认重要数据已经备份。

### 生成的密码可以重复点击吗？

可以。每次点击都会重新生成随机密码。

### 忘记工作区自定义密码怎么办？

KeyRing 不提供云端找回。请妥善保管密码及历史备份。系统验证模式使用设备已有的身份验证方式。
