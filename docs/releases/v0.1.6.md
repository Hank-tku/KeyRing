# KeyRing v0.1.6

版本：0.1.6+2004 · 2026-10-04

## 新增

- 从 Chrome 导出的密码 CSV 导入账号、密码、网址和备注，支持预览、重复识别和冲突处理；可再次导入更新，不是后台持续同步。
- 工作区与分组管理，支持全设备同步、仅移动端同步和仅本机保存，并传播删除记录。
- 工作区访问验证：可选择系统验证（设备支持的指纹、面容或设备密码）或独立自定义密码；切换受保护工作区时重新验证。
- 支持密码2、密码3及自定义名称的保密项，首页和详情均可独立查看、隐藏和复制。
- 应用进入后台满两分钟自动锁定，覆盖详情、编辑、设置与桌面隐藏窗口。

## 改进与修复

- 调整首页条目布局，统一右侧按钮尺寸与对齐；工作区管理操作和拖拽手柄不再重叠，窄窗口使用菜单。
- 详情完整展示网址与备注，编辑后留在详情页并刷新内容。
- 桌面快捷键只打开快速填充面板，锁定时也在面板内验证，不弹出主窗口。
- macOS 应用名称统一为 KeyRing，保持原有应用标识和数据库路径。
- 手机系统自动填充排除受保护工作区；iOS 扩展只读取可填充条目的独立副本。
- 发布前统一执行静态检查和测试，四个平台构建全部成功后才公开安装包，附带 SHA-256 校验文件。

## 下载与升级

- macOS：解压 `KeyRing-macOS-v0.1.6.zip`，应用名为 `KeyRing.app`；最低 macOS 12。该包未经过 Apple 公证。
- Windows：解压 ZIP 后运行应用，保留同目录依赖文件。
- Android：按设备架构选择 APK，多数手机使用 `arm64-v8a`。使用正式发布密钥签名，构建号为 2004。
- iOS：提供未签名应用 ZIP，需要自行签名，不能直接作为 App Store／TestFlight 安装包使用。

升级前请备份数据。工作区验证设置仅在本机生效，不随同步或导出传输；它属于应用内访问控制，SQLite 条目库仍为明文存储。

## 验证范围

本地静态检查、107 项自动测试与 macOS Release 构建通过，并用合成数据检查桌面布局。后台锁定边界与系统验证失败／取消路径有自动测试；真实生物识别成功操作、双设备同步和 Windows／移动端设备验收未在本次完成，构建通过不代替设备实测。
